# Role Playbooks

Use role playbooks for keyword extraction and evidence phrasing. Do not force all keywords into the resume.

## 产品经理

Signals:

- 用户洞察, 需求分析, PRD, 原型, 数据分析, A/B测试, 竞品分析, 项目推进, 跨部门协作.

Evidence:

- Feature shipped, conversion improved, process shortened, user complaints reduced, adoption increased.

## 新媒体/内容运营

Signals:

- 选题, 标题, 内容矩阵, 小红书/抖音/公众号/B站, 评论区运营, 私域承接, 数据复盘.

Evidence:

- Views, saves, comments, leads, conversion, account growth, content production volume.

## 用户/活动/增长运营

Signals:

- 拉新, 留存, 转化, 裂变, 活动策划, 用户分层, 社群, CRM, 数据看板.

Evidence:

- Signup, activation, retention, CAC, conversion rate, activity participation, GMV.

## 数据分析

Signals:

- SQL, Python, Excel, BI, 指标体系, A/B测试, 漏斗分析, 留存分析, 归因分析.

Evidence:

- Decision supported, dashboard adoption, analysis cycle shortened, metric anomaly found.

## 软件开发

Signals:

- Language/framework stack, architecture, API, database, cache, concurrency, testing, CI/CD, observability.

Evidence:

- Module ownership, performance improvement, stability, incident reduction, delivery quality.

## 测试工程师/QA

Signals:

- 测试策略, 自动化框架, Pytest/Selenium/Playwright/Appium, 接口测试, 性能测试, CI/CD, 质量门禁, 缺陷定位, 微服务链路, AI Agent/LLM评测, 对话流验证.

Evidence:

- Framework built or extended, coverage/automation rate improved, CI pipeline integrated, defects found/prevented, regression cycle shortened, quality metrics improved, evaluation rubric designed.

Common weak evidence:

- Only says `负责测试` without strategy, scope, cases, tools, defect examples, metrics, or release impact.
- Claims framework ownership but cannot explain architecture, maintainability, reporting, data setup, or flaky-case handling.
- Claims AI/LLM testing but cannot explain expected-output criteria, scoring rubric, prompt/test set design, or non-deterministic output handling.

Do not exaggerate:

- Do not write `从0搭建`, `测试负责人`, `质量体系`, `精通自动化`, or `AI评测体系设计` unless evidence supports ownership, design decisions, and defensible outcomes.

## 销售/BD

Signals:

- 客户开发, 商机推进, 需求挖掘, 方案演示, 谈判, 回款, 渠道, 复购.

Evidence:

- Leads, conversion, revenue, average deal size, payback cycle, renewal, key accounts.

## 设计

Signals:

- UX, UI, interaction, design system, user research, prototyping, portfolio, usability.

Evidence:

- Portfolio links, shipped features, conversion/task success improvement, consistency gains.

## 财务/会计

Signals:

- 凭证, 报表, 成本, 预算, 税务, 审计, 应收应付, Excel, ERP.

Evidence:

- Closing efficiency, error reduction, reporting quality, compliance, cost control.

## 行政/HR

Signals:

- 招聘, 入离转调, 员工关系, 薪酬绩效, 培训, 供应商, 固定资产, 流程优化.

Evidence:

- Hiring cycle, onboarding efficiency, process coverage, employee satisfaction, cost control.
