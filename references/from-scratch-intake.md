# From-Scratch Intake

Use this when the user has no old resume, no raw experience draft, or only category labels such as school, major, tools, certificates, or target role. The first deliverable is `经历采集清单.md`, not a resume.

## Key Rule

Category labels guide questions; they are not resume facts. Do not turn `会Python`, `做过销售`, `学生会`, `懂财务`, or `想做运营` into experience bullets without concrete evidence.

## Three-Stage Intake

Ask no more than 5 questions per round.

### Round 1: Find the Most Relevant Evidence

Ask for:

```text
目标岗位/JD：
最接近目标岗位的一次经历或作品：
你实际做了什么：
用过的工具/方法/系统/资质：
可展示的产物或结果：
```

If the user has many experiences, ask them to start with the one most related to the target role.

### Round 2: Deepen Mentioned Facts

Only ask about experiences the user already mentioned. Collect:

```text
对象/场景：
个人动作：
方法/工具：
交付物：
结果/反馈：
可验证材料：
不可夸大点：
```

### Round 3: Fill Critical Gaps

Ask only for missing facts that affect the JD top 3 capabilities, hard requirements, or the main selling point. If facts are still weak, provide a gap-closing path instead of writing a fake resume.

Exit early if the JD top 3 capabilities already have defensible evidence and no hard gate is failing.

## Evidence Sources

- Work/internship: role, service object, tasks, difficulties, outputs, results.
- Project/case: background, goal, personal action, tools/methods, deliverable, result, review.
- Portfolio/output: code, design, report, lesson plan, sales plan, operation calendar, workflow document, analysis, screenshots.
- Client/service/collaboration: audience, customer type, stakeholder, issue handled, feedback.
- Skill/certificate/compliance: certificate, qualification, system, standard, industry rule.
- Performance/quality/efficiency: revenue, conversion, cost, cycle time, accuracy, complaint rate, defect rate, delivery volume, team scale.
- Confidential work: anonymize customer/project names; use industry, scale, responsibility, and range-based results.

## Gap-Closing Suggestions

Suggestions must be concrete, feasible, related, and verifiable:

- Concrete output, not just "learn X": code, document, report, portfolio page, screenshot, case analysis.
- Finishable in about 8 hours / 3 days.
- Directly tied to the target JD.
- Easy to show with a link, file, screenshot, or written artifact.

Examples by gap type:

- Missing project: build a mini project or case in the target direction.
- Missing tool use: create a small practice artifact with the target tool.
- Missing business understanding: write a product, industry, customer, or process analysis report.
- Missing metrics: cannot be invented quickly; use conservative wording or change target.
- Missing degree/certificate/license: cannot be quickly patched; adjust target or highlight other strong evidence.
