# Interview Question Playbooks

Use this reference when creating `面试追问预测.md`.

## Public Research Protocol

When company or role-specific preparation matters, search public pages with queries like:

- `牛客 <公司> <岗位> 面经`
- `牛客 <岗位> 项目经历 面试问题`
- `脉脉 <公司> <岗位> 面试`
- `BOSS直聘 <岗位> 面试问题`
- `看准 <公司> <岗位> 面试`
- `职朋 <公司> <岗位> 面试`
- `应届生求职网 <公司> <岗位> 面经`

Do not log in, bypass permissions, or quote private content. If useful content is behind login or in a screenshot, ask the user to paste the text.

## Question Output Format

For every predicted question, include:

```text
问题：
为什么会问：
考察点：
回答框架：
结合你经历的建议答法：
危险回答：
```

## Universal Questions

- 请做一个1分钟自我介绍。
- 为什么看这个岗位/公司？
- 你最有代表性的项目是什么？
- 这个项目里你的个人贡献是什么？
- 结果指标怎么计算？有没有数据口径？
- 遇到最大的困难是什么？你怎么处理？
- 如果重新做一次，你会怎么改？
- 你和团队/上级/客户意见不一致时怎么推进？
- 你的短板是什么？准备怎么补？
- 期望薪资、到岗时间、职业规划是什么？

## Product Roles

- 如何判断一个需求该不该做？
- 你如何定义核心用户和使用场景？
- 讲一个你做过的产品/功能，指标是什么？
- 如果 DAU/转化率下降，你怎么排查？
- 竞品分析怎么做？结论如何落地？
- PRD怎么写？如何推动研发和设计？

## Operations and Content Roles

- 你如何做选题和内容复盘？
- 你如何判断一条内容能不能爆？
- 活动转化低怎么定位问题？
- 用户增长/留存/转化分别看哪些指标？
- 预算有限时怎么做增长实验？
- 讲一个失败案例和复盘。

## Data Roles

- SQL查询、窗口函数、分组聚合、留存分析。
- A/B测试怎么设计？样本量和显著性怎么看？
- 指标异常怎么定位？
- 业务方给你一个模糊问题，你怎么拆解？
- 你做过的数据看板服务了什么决策？

## Development Roles

- 项目架构、核心模块、技术选型、性能优化。
- 线上问题怎么排查？
- 数据库索引、并发、缓存、消息队列、接口设计。
- 你负责的代码边界是什么？
- 如何保证质量、测试和可维护性？

## Sales and BD Roles

- 你如何开发客户？
- 讲一个从线索到成交的完整案例。
- 客户拒绝或压价时怎么处理？
- 你负责过的客单价、转化率、回款周期是多少？
- 如何判断客户真实需求？

## HR and Behavioral Questions

- 离职原因。
- 为什么转行/换城市/换行业？
- 你最看重团队什么？
- 你能接受加班/出差/压力吗？
- 你有什么想问我们的？

Recommend safer reverse questions:

- "这个岗位入职前三个月最重要的目标是什么？"
- "团队现在最希望这个角色解决的业务问题是什么？"
- "这个岗位和产品/运营/销售/研发的协作方式是怎样的？"
