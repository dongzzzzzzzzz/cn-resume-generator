# Common Resume Problems

Use this as the QA checklist before finalizing.

## Domestic HR Screening Problems

- JD keywords are missing or buried.
- First screen does not reveal target role fit.
- Responsibilities are listed without outcomes.
- Results are vague: `提升明显`, `效果良好`, `获得认可`.
- Claimed scope is bigger than evidence: `主导`, `统筹`, `从0到1` without proof.
- Project ownership is unclear.
- Timeline has unexplained gaps or overlapping dates.
- One generic resume is used for every role.
- Contact details or filename look unprofessional.
- Important details are trapped in images, graphics, or complex tables.

## AI Flavor Problems

- Over-polished consulting language.
- Too many abstract nouns: `赋能`, `闭环`, `抓手`, `沉淀`, `生态`.
- Every bullet has the same rhythm.
- Metrics look invented or too perfect.
- Candidate sounds more senior than their actual experience.
- Template placeholders are used as facts: `[项目名称待确认]`, `[待确认]个客户/缺陷/活动`, `负责[事项待确认]`.

Fix by:

- Replacing abstract claims with specific context and action.
- Keeping only metrics the user can defend.
- Using plain Chinese that a real candidate could say in interview.
- Adding a fact-confirmation list for uncertain claims.
- Removing placeholder facts from resumes and platform scripts; keep them only in intake/audit files.

## Expression Upgrade Boundaries

Allowed:

- Add confirmed tools to confirmed actions: `写测试` -> `使用Pytest编写测试用例`.
- Make oral wording professional: `帮着组织活动` -> `协助组织学生活动`.
- Clarify action without changing scope: `测了几个接口` -> `完成接口功能测试`.

Forbidden:

- Upgrade responsibility: `协助/参与` -> `主导/负责核心`.
- Expand scope: `几个脚本` -> `自动化测试框架`; `一次活动` -> `活动体系`.
- Add results: `完成` -> `显著提升`; `做了` -> `优化XX指标`.
- Add unmentioned methods, processes, tools, metrics, customers, certificates, team size, or project names.
- Turn category labels into experience: `会Pytest` -> `基于Pytest搭建自动化测试框架`.

If the user asks to fabricate experience, refuse the fabrication briefly and offer alternatives: a mini project, tool practice artifact, portfolio/report, safer target role, or learning path. Do not relax the evidence standard.

## Good Bullet Pattern

Use:

```text
在<业务场景>中，负责<个人动作/职责边界>，使用<工具/方法>，产出<交付物/结果>。
```

Stronger when measurable:

```text
围绕新客转化低的问题，负责小红书内容选题和评论区线索承接，3个月发布120篇笔记，单篇最高曝光8.6万，将私信咨询量从每周约20条提升到约55条。
```

Avoid:

```text
负责新媒体运营，提升品牌影响力，获得领导认可。
```

## Formatting Rules

- Use clean single-column layout by default.
- Keep attachment resume to 1 page for internship/campus when possible, 1-2 pages for most social hiring, 2 pages for senior roles if needed.
- Use standard headings: 个人优势, 工作经历, 项目经历, 教育经历, 技能证书.
- Do not use photos by default unless the role or user requires it.
- Do not include ID number, marital status, full home address, ethnicity, or private family details.
