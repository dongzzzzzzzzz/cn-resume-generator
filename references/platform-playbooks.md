# Platform Playbooks

Use platform-specific outputs instead of one generic resume everywhere.

## Truthfulness Rules

- Platform scripts, online paste versions, hunter summaries, and referral messages must share the same fact source as the attachment resume.
- Use only the strongest 1-2 confirmed evidence points in opening messages.
- Do not upgrade claims to improve response rate: no stronger ownership, wider scope, invented metrics, unconfirmed tools, or unverified seniority.
- If the resume is a conservative/risk-first version, platform copy must be conservative too.
- If facts are insufficient for a resume, do not create persuasive platform scripts; ask for evidence or provide an intake checklist.

## BOSS直聘

Reality: direct chat and first-screen matching matter. The opening message can change response rate.

Optimize:

- Profile title and personal advantage section.
- First 3 lines: target role, strongest matching evidence, availability or industry fit.
- Short, concrete opening messages.

Output:

- `BOSS开聊话术`:稳妥版, 结果导向版, 差异化版.
- `在线简历粘贴版`: avoid tables and formatting that break in fields.

## 智联招聘

Reality: online resume fields, attachment resume, enterprise/campus screening, and keyword search all matter.

Optimize:

- Complete field coverage.
- Standard section titles.
- Attachment resume filename.
- Campus-portal compatibility when relevant.

Output:

- `智联在线简历字段版`
- `附件简历`
- `网申关键词检查`

## 猎聘

Reality: hunters need a forwardable story and seniority signal.

Optimize:

- Career stability and motivation.
- Business scale, level, compensation expectation language.
- Hunter summary that can be copied into a recommendation message.

Output:

- `猎头沟通摘要`
- `候选人亮点3条`
- `潜在顾虑与解释`

## 脉脉

Reality: professional identity, weak ties, referral requests, and target-company context matter.

Optimize:

- Professional profile headline.
- Personal brand summary.
- Referral request message.
- Target-company networking message.

Output:

- `脉脉主页优化版`
- `内推请求话术`
- `目标公司人脉沟通话术`

## 拉勾

Reality: internet roles, product/operation/tech stacks, project links, and growth metrics matter.

Optimize:

- Role keywords and stack.
- Project links, portfolio, GitHub/Gitee, demo, product screenshots.
- Metrics and ownership for product, operations, design, development, and data roles.

Output:

- `拉勾互联网岗位版`
- `作品链接呈现建议`

## 校招网申

Reality: fields and conservative parsing matter more than visual flourish.

Optimize:

- Education and graduation details.
- Internship, campus, competition, project, and open-question material.
- ATS-compatible attachment: single column, standard headings, no image-only key info.

Output:

- `校招网申字段版`
- `开放题素材`
- `面试前补课清单`
